# NOW-001 — Present-moment orientation

Date: 2026-10-04.

Baseline: `15e0ac7dcc2cbf54e6cd43c9ac60bf0f74391604`.

## What this adds

`projectPresentMomentOrientation` in `projections/presentMomentOrientation.ts` returns two members:

- `orientation`, from `projectCurrentTemporalOrientation`
- `thread`, from `projectResume`

The caller supplies the instant and the confirmed IANA zone. The function does not read the clock, the network, or Supabase. It does not write. It does not rank the members, infer a thread, infer current Context, or add Today, Must Do, Due, Planned, Notes, or a next action.

`composePresentMomentOrientation` in `components/presentMomentReading.ts` uses the existing source-read result. The composition is complete only when Work, Protected Time, Blocks, Commitments, the Active Thread read, and the open-Task read have all succeeded. A failed temporal source is not an empty orientation. A failed Active Thread or open-Task read is not an absent thread. A ready Active Thread read with no row remains a real absence. A ready open-Task collection that does not contain the referenced Task still follows Resume.

## Unchanged

No schema, migration, dependency, route, or Tasks-screen change. Current temporal orientation and Resume keep their own functions. The experience is not designed. The product name stays Orient. The repository name stays `workday`.
