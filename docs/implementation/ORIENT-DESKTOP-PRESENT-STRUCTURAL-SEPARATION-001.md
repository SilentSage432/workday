The whole-day signature is not in that reading. It is not hidden, thinned, renamed, or given reserved space. There is no replacement day visualization. Exact time calls the existing entry with no minute, the same `enterExact` path. It does not sit on a day rail.

Present membership is unchanged: `composeCurrentTemporalReading`. Removing the signature does not change which facts contain the instant.

## Day

Desktop Day remains the selected civil day: the date, quiet Now when that day is today, established truths for that day, the Active Thread, the whole-day signature, the Now mark inside that signature when the day is today, and Exact time.

A day that is not today has no Now mark and no clock chase. Same-day facts stay clock times. A fact that leaves the selected day keeps both dates.
