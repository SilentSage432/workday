# PRODUCTION-IDENTITY-001 — Orient mark on the instrument

The production instrument is coherent enough to carry its identity. This places the supplied Orient lockup. It does not redesign the temporal reading.

## Asset

The source file is `/Users/silentsage/Desktop/Orient_Logo.png`. It was copied unchanged.

The runtime file is `public/orient-logo.png`. The instrument loads `/orient-logo.png`. It does not read the Desktop path.

The PNG is 2182 × 721 pixels, RGBA, 1,182,123 bytes. It has a true alpha channel: about 59.8% of pixels are fully transparent and about 40.2% are partially transparent. None are fully opaque. The copy matches the source byte for byte. The Desktop file was not edited.

## Placement

Temporal orientation owns the upper left. Instrument identity owns the upper right.

`OrientIdentity` is one mark on the instrument, shared by phone and desktop. It is not inside Day, Present, Week, or Month, so changing question does not add another copy and does not move it.

On the phone it sits in the upper right of the field, opposite the date and Now. The where-line keeps clear of it horizontally. The signature and the rest of the portrait column are not given a header and are not pushed down.

On the desktop the same mark sits in the quiet upper right of the instrument, in the dock's open top, not across the clock. It is only slightly larger than the phone mark.

Displayed size follows the artwork's ratio. Nothing crops, stretches, recolors, shadows, or plates the image. PRODUCTION-IDENTITY-001A raises only the optical scale: phone height is 2rem, about 18% above the first 1.7rem; desktop height is 2.77rem, about 35% above the first 2.05rem. Position is unchanged.

The mark is not a control. It does not go Home, return to Now, or open anything. Pointers pass through it.

The image is named "Orient". That is the accessible name of the artwork, not the filename. The instrument landmark already uses that word.

## Preservation

Phone entry is still Day on the authoritative civil date. Desktop entry is still Present. Exact time, Capture, Week, Month, Direction, and the temporal field are unchanged aside from this corner mark.

Physical size is an initial restraint. It should be tuned on the real phone and desktop.
