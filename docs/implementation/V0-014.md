## Interaction evidence

Current evidence, pending the phone acceptance below:

Touch time to talk about time. Touch established truth to talk about that truth.

- A short tap on a painted established fact refers to that fact.
- A hold, then a drag, that begins on that fact refers to the time. The hold is still 220ms. The slop is still 10px.
- Movement past that slop before the hold is a scroll. It does not refer to the fact and it does not start a temporal selection.
- This is an interaction distinction. It is not a domain priority among Work, Protected Time, Blocks, and Commitments.

The phone has not yet accepted this grammar. Until it does, this is the implementation under test, not a finished rule.

## What a fact reference is

The reference is React state on the day session: the fact's existing source kind and source id. It points at a fact the day already shows. It is not a copy, not a new object, and not a column.

Nothing about "selected" is written. The Timeline projection is unchanged. Save is unchanged. Remounting the day, which Save already does, drops the reference because the session remounts.

A fact reference and a temporal selection do not stay up together.

- Tap a fact from idle: that fact is referenced. No 15-minute range is created.
- Tap temporal territory that is not on a painted fact: the existing 15-minute temporal selection. A prior fact reference is cleared.
- Hold or drag that begins on a fact: temporal selection. A prior fact reference is cleared.
- Scroll: neither a new fact reference nor a new temporal selection.
- Close: the fact reference is gone.
- Tap another fact: the new reference replaces the old one.
- Tap a fact while a temporal selection is open: the fact is referenced and the temporal selection closes. A press inside the current temporal band that is not a short tap on a fact still does not start a replacement range. A drag that starts inside that band still does not replace it.

## How the tap finds the fact

The articles stay `pointer-events: none`. The transparent surface remains the only pointer target, so a hold can still begin on top of a fact.

On pointer down, the surface compares the point with each article's rendered box. The box that contains the point and paints above the others is the candidate. Higher computed `z-index` paints above. When those values are equal, the later article in the column paints above. That is the canvas stacking. It is not a ranking of kinds.

Work and Protected Time are context paint. Protected Time is painted after Work and uses a higher layer, so a point in both boxes refers to the Protected Time. Blocks and Commitments use lanes. A point in one lane refers to the fact in that lane. Where the current paint makes the targeted fact ambiguous, this tranche does not invent a winner.

## Acknowledgement

The referenced article gets a stone outline, using the same light already used for a temporal band. A short readout above the axis shows the kind, the existing label, title, or purpose, and the visible time range. Close is the only control. There is no Edit, Delete, Move, Resize, Duplicate, or Convert.

## Tests

Interaction tests cover a tap on each kind, the visible reference, the absence of a persistence call, hold-and-drag from each kind, slop that selects neither, a temporal range that still crosses a Block and a Commitment, replacement, dismissal, and the absence of editing controls.

happy-dom does not lay out the column and does not hit-test. Those tests place article boxes and dispatch events on the surface. They show that the gesture uses those boxes. They do not prove what a finger hits in Chrome.

## Phone acceptance

On Samsung/Chrome, after this build is deployed:

A. Tap the existing striped Protected Time. The system acknowledges that Protected Time. It does not create a 15-minute temporal selection under it.

B. Dismiss that acknowledgement.

C. Put a finger on the Protected Time, hold briefly, then drag. A temporal selection begins and can paint through the Protected Time.

D. Start a scroll with the finger on the Protected Time. The canvas scrolls. Neither a fact reference nor a temporal selection is created.

E. If a Block or a Commitment is on the day, tap the one that is visibly under the finger. That fact is acknowledged.

This phone test is the acceptance authority.
