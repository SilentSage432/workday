## Day

Desktop Day was a thin inscription on a horizontal line, with the rest of the field left empty. The same whole-day signature is now a shallow temporal field for the selected civil day, from 00:00 to 24:00.

Horizontal position is still time of day. The field has vertical depth. Established truth is drawn as the existing hue contours through that depth, proportional to the interval, without a filled block. Overlapping truths still share the point. Unmarked time stays unmarked. It is not described as free or available.

The factual reading and the Active Thread stay above the field. The thread does not occupy time in the field. Quiet Now and the field's Now reference appear only when the selected day is today. Exact time stays the precision control under the field and still opens the existing Day clock.

The field does not grow to the viewport. It is one civil day, not a schedule grid.

## Unchanged

Present, phone reading, Week, Month, Direction, the Exact time frame, the drawer, the bottom reach, DayClock, projections, and the auth bootstrap are unchanged.
