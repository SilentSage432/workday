# Product name

Date: 2026-10-04.

Baseline: `ab3e30ead63899eef4a4749b17063f5b04fe8b25`.

## Decision

The product name is Orient.

Orient is the temporal orientation system being built in this repository.

`workday` remains the repository and folder name. That name is an implementation and history detail. It does not define product identity. This decision does not rename the repository.

The name reflects the system's established purpose: helping the human orient and reorient within time, established reality, and explicit intention, while preserving human authority.

Orient is not a claim that the system decides direction, importance, priority, or action for the human.

## What this decision does not do

It does not change domain semantics, architecture, persistence, runtime behavior, or the present-moment orientation contract in [2026-10-04-present-moment-orientation.md](2026-10-04-present-moment-orientation.md).

It does not rename:

- the GitHub remote
- the Supabase project
- the Vercel project
- URLs
- the package name
- database identifiers
- environment variables
- architecture identifiers
- code symbols
- routes
- runtime UI copy
- the manifest or other app metadata

It does not create a logo, a tagline, branding language, or a visual design. Applying the name to those surfaces, if needed, is a later bounded tranche.

## Context

NOW-CONTRACT-001 left the product name outside its composition decision and recorded that Orient was not adopted there. That boundary stays true of that contract. This record is the later human decision that chooses the name.

Historical documents use "Workday" for the effort as it was then called. Those sentences stay historical.

## Consequences

- Current-authority documents state the product name as Orient and keep `workday` as the repository name.
- Sentences that still say no product name has been chosen are not current naming authority once they point here.
- No application title, manifest, package metadata, route, or runtime copy changes in this decision.
